# 2026-11-18

## 修复 TurnTheOrientation 项目编译报错（包版本与编辑器不匹配）

- 环境：Unity 6000.3.10f1（D:/UnityEditor/Unity 6 (6000.3.10f1)），项目 D:/UnityProjects/TurnTheOrientation，URP 2D 模板，Assets 几乎为空。
- 报错根因（Editor.log 中仅 2 类 error CS）：
  - com.unity.inputsystem 1.12.0 编译失败：`error CS0117: 'BuildTarget' does not contain a definition for 'ReservedCFE'`（6 次）。
  - com.unity.collab-proxy 2.6.0 编译失败：`error CS0104: 'ObjectInfo' is an ambiguous reference between 'Codice.CM.Common.ObjectInfo' and 'UnityEditor.ObjectInfo'`（12 次）。
  - 连带影响：`TypeLoadException: Could not load type 'UnityEngine.InputSystem.InputActionAsset'`；2d.animation 10.1.4 的 USS 报 "Unsupported selector format"。
- 修复：把 Packages/manifest.json 全部对齐到编辑器 6.3 自带版本（来源：编辑器内置
  Data/Resources/PackageManager/Editor/manifest.json）。
  inputsystem 1.18.0、collab-proxy 2.11.3、2d.animation 13.0.4、2d.aseprite 3.0.1、2d.psdimporter 12.0.1、
  2d.spriteshape 13.0.0、2d.tilemap.extras 6.0.1、2d.tooling 1.0.2、ide.rider 3.0.39、ide.visualstudio 2.0.26、
  URP 17.3.0、test-framework 1.6.0、timeline 1.8.10、visualscripting 1.9.9。com.unity.pipeline 0.5.0-exp.1 保持不变。
  备份：Packages/manifest.json.bak。
- 结论：报错不是用户脚本问题，是旧模板包的 API 与 Unity 6.3 不兼容。以后新建项目请直接用 6.3 自带模板。
